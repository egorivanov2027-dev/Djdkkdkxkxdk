# True VPN Bot 🔒

Telegram-бот для управления VPN-подписками (Remnawave + CryptoBot + Stars + СБП).

---

## 📁 Структура файлов (всё в одной папке)

```
truevpn_bot/
├── main.py              ← ТОЧКА ВХОДА (сюда вводи свои данные)
├── config.py            ← Все настройки
├── database.py          ← SQLite (aiosqlite)
├── remnawave.py         ← API-клиент панели Remnawave
├── keyboards.py         ← Все клавиатуры бота
├── handlers.py          ← Основные обработчики (пользователи)
├── admin_handlers.py    ← Админ-панель
├── payment_handlers.py  ← Оплата (CryptoBot, Stars)
├── requirements.txt     ← Зависимости
└── truevpn.db           ← База данных (создаётся автоматически)
```

---

## ⚙️ Настройка (main.py)

Открой `main.py` и заполни:

```python
config.BOT_TOKEN    = "1234567890:AAF..."      # токен от @BotFather
config.ADMIN_IDS    = [123456789]              # твой Telegram ID
config.PANEL_URL    = "https://your-panel.com" # URL Remnawave-панели
config.PANEL_TOKEN  = "eyJ..."                 # API-токен панели
config.CRYPTO_BOT_TOKEN = "12345:AAA..."       # токен от @CryptoBot
config.SBP_ADMIN_LINK   = "https://t.me/you"  # ссылка на твой ЛС
```

---

## 🚀 Запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить бота
python main.py
```

| Метод | Описание |
|-------|----------|
| **CryptoBot** | USDT/TON — автоматически через @CryptoBot |

## 👤 Функции пользователя

- `/start` — приветствие + главное меню
- 💎 Пробный период — 3 дня бесплатно (1 раз)
- 🛒 Купить VPN — выбор плана и оплата
- 🔗 Подключиться — инструкции для Android/iOS/Windows/macOS + QR-код
- 📱 Устройства — список подключённых устройств
- 👤 Профиль — статус подписки, детали
- 🔄 Продлить — продление активной подписки
- ❓ Помощь — ссылки на поддержку и канал

---

## 🛠 Функции администратора

Команды:
- `/admin` — открыть панель
- `/givesub <user_id> <plan_id> <devices>` — быстрая выдача  
  Пример: `/givesub 123456789 1m 1`

Через панель `/admin`:
- 📊 Статистика (пользователи, подписки, выручка)
- 👥 Список пользователей
- ➕ Выдать подписку (по ID, для СБП-оплат и подарков)
- 📢 Рассылка всем пользователям

## 🔧 Remnawave API

Бот создаёт пользователей через `POST /api/users`.  
В ответе должен быть `subscriptionUrl` — ссылка для подключения.

Убедись, что в панели включён API и токен указан верно.

## ⭐ Telegram Stars

1 звезда = `STARS_RATE` рублей (по умолчанию 2 ₽).
